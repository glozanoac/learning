# Mathematical and Computational Modeling - IMCA

The program teaches how to describe real problems with mathematics and solve them with computers. The full study plan is in [`curriculum.pdf`](./curriculum.pdf).

## Structure

Work is organized by semester, named `YYYYS` (year + semester number):

```txt
IMCA/
|- curriculum.pdf
|- 20262/                     2026-II
    |- courses/
    |   |- MMC006/            Inferential Statistics and Data Analysis (local only)
    |   |- MMC007/            Optimization
    |   |- MMC201/            Theory and Models of Machine Learning
    |- optimization-group/    Mining optimization formulations (local only)
```

Each course folder follows the same layout where possible: `classes/` (lecture notes), `exercises/` (my solutions: handwritten `.rnote`, typeset `.tex`, code), and a `*_reading_plan.tex/.pdf` that maps the syllabus to reference books.
