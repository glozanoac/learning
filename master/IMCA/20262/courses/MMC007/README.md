# MMC007 - Optimization

Continuous optimization: optimality conditions, line search, Newton and quasi-Newton methods, trust region, conjugate gradient, constrained optimization (KKT, duality).

Main references: Nocedal & Wright, *Numerical Optimization* (2nd ed.), and Bertsekas, *Nonlinear Programming* (3rd ed.).

## Structure

| Path | Contents |
|---|---|
| `syllabus.pdf` | Course syllabus |
| [`classes/`](./classes/) | Lecture notes per chapter, plus complementary proofs in `extra/` (see its README) |
| `exercises/` | My solutions, numbered by class: handwritten `.rnote`, typeset `.tex/.pdf` |
| `exercises/src/` | Python implementations: line search, descent, Newton, quasi-Newton, Cholesky, linear CG, projected gradient, and the scripts for each problem (`P*.py`) |
| `optimization_complete_map.html` | Interactive map of the course: chapters, what comes next, and problems you can solve (open in a browser) |
