# Master's Degree

Formal coursework of my master's degree.

| Program | Institution | Directory |
|---|---|---|
| Master in Mathematical and Computational Modeling | IMCA (Instituto de Matematica y Ciencias Afines) - UNI (Universidad Nacional de Ingenieria), Lima, Peru | [`IMCA/`](./IMCA/) |

In plain words: the program teaches how to describe real problems (like planning a mine) with mathematics and solve them with computers.

My topics of interest in the program are in optimization under uncertainty: stochastic mixed-integer programming and stochastic dynamic programming (see the research lines in the [root README](../README.md)). The gaps the program leaves are covered in [`../self/studies/`](../self/studies/).
