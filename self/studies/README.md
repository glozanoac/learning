# Open-Pit Mining Optimization Studies

The objective of this directory if to cover the gaps of foundational knowledgment to be capable of solve complex problems that arise in `open-pit mining operations`.

## Scope
* Cut-off Grade Optimization
* Real-Time Operational Dispatching & Logistics

## Metodology
1. **Mathematical Foundations:** Developing proofs, understanding convergence behavior, and analyzing algorithm complexity.
2. **Prototyping (Python):** Implement unoptimized algorithm with the objective to compute analytical solutions
